# Experiment Protocol

Compare at least two organizational baselines:

A. Monolithic / single-agent implementation.
B. DH-ADOM hierarchical implementation.

Control:

- same model family where possible
- same repository
- same task set
- same tool permissions
- same compute budget
- same evaluator

Record:

- task completion quality
- changes requested outside scope
- agent count
- delegation depth
- cost
- latency
- validation coverage
- recovery behavior
- handoff quality
- governance violations

No superiority claim should be made without the raw results and methodology.
