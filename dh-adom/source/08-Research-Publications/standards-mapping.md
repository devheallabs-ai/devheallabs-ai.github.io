# DH-ADOM Standards / Ecosystem Mapping

| Ecosystem | Relevant scope | DH-ADOM mapping |
|---|---|---|
| NIST AI RMF | AI risk management | Risk and evidence lifecycle mapping |
| NIST Agent Identity & Authorization | Agent identity, authorization, audit | Agent Registry, identity, permission, delegation controls |
| ISO/IEC 42001 | AI management system | Organizational governance context |
| OWASP Agentic Applications | Agentic security risks | Security and adversarial validation inputs |
| MCP | Agent/tool connectivity | Tool governance and permission boundary |
| A2A | Agent-to-agent interoperability | Parent/child communication with preserved governance context |
| AGENTS.md | Repository agent instructions | Root instruction layer; Feature Agent artifacts add local ownership |
| AI-SDLC Framework | AI-assisted software lifecycle | Lifecycle integration and quality-gate mapping |

DH-ADOM is complementary to these artifacts and does not replace them.
