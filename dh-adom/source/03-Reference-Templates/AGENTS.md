# AGENTS.md — DH-ADOM Root Instructions

The repository uses DH-ADOM.

The Root Agent orchestrates project work. Feature Agents own bounded domains. Specialist Agents assist within delegated scope.

Before modifying code:

1. Read the Engineering Constitution.
2. Read AI-SDLC and ADLC state.
3. Identify the feature owner.
4. Inspect existing implementation and tests.
5. Create or load the appropriate delegation/task contract.
6. Implement only within authorized scope.
7. Validate and record evidence.
8. Update state and handoff.

Never bypass feature ownership or delegation governance.
