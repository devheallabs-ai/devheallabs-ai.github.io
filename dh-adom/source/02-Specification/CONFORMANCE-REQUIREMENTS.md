# DH-ADOM v1.0 Conformance Requirements

An implementation MUST satisfy all CRITICAL requirements and provide evidence for each requirement.

| ID | Requirement | Class |
|---|---|---|
| CR-001 | Engineering Constitution exists and is authoritative | Critical |
| CR-002 | Root Agent exists and is identifiable | Critical |
| CR-003 | Feature Agent ownership exists for meaningful domains | Critical |
| CR-004 | Specialist delegation is bounded | Critical |
| CR-005 | Delegation contracts are auditable | Critical |
| CR-006 | Root does not silently bypass Feature Agent ownership | Critical |
| CR-007 | AI-SDLC state is represented | High |
| CR-008 | ADLC state is represented for agents | High |
| CR-009 | Agent identity is separate from model identity | High |
| CR-010 | Agent permissions are explicit | Critical |
| CR-011 | Autonomy/delegation budgets are enforced | Critical |
| CR-012 | Agent creation is bounded | Critical |
| CR-013 | State and handoff are persisted | High |
| CR-014 | Requirement-to-evidence traceability exists | High |
| CR-015 | Audit trail records delegation and material actions | High |
| CR-016 | Cross-feature changes are controlled | Critical |
| CR-017 | Failure / timeout handling exists | High |
| CR-018 | Fresh-session resumability is demonstrated | High |
| CR-019 | No claimed completion without validation evidence | Critical |
| CR-020 | Conformance results are reproducible | High |
