# DH-ADOM

This folder contains the public research pages, diagram assets, versioned downloads and current publication source.

- Start: https://devheallabs.com/dh-adom/
- Adopt: https://devheallabs.com/dh-adom/adoption/
- Current source: source/
- Immutable earlier downloads: releases/1.0.0/
- Current publication: releases/1.1.0/

The website generator is .github/scripts/build-dh-adom.py. The PDF/vector builder is .github/scripts/build-dh-adom-documents.py (ReportLab and Arial/Consolas fonts on Windows). The current paper source is source/01-White-Paper/paper.json. No source package is a complete production runtime or conformance certification.
