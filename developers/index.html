Developers

Build Your First AI System

Discover → Install → Build → Run → Evaluate → Simulate → Deploy. The first three steps take minutes today; the last two are where the platform is still being built.

Try the Playground View on GitHub
Step 1

Discover

Read the Technology page or try NC live in the browser playground — no install needed.

Step 2

Install

Single binary, no runtime dependencies. See install docs on GitHub.

Step 3

Build

Write a service, an agent, or a UI in plain English. See examples in nc-apps.

Step 4

Run

NC compiles to a single binary — run it locally or wherever you deploy binaries today.

Step 5

Evaluate

A dedicated Evaluation Engine is on the roadmap — today, evaluate manually against your own test scenarios.

Step 6

Simulate

The DevHeal Simulator is in research — see Technology.

Step 7

Deploy

Ship the binary anywhere. For self-healing operations at runtime, layer in HiveANT or SwarmOps.
