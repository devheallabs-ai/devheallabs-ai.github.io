Hands-on developer verification

Verify NC & offline local inference in 60 seconds.

You do not need a sales call to verify our core compiler and local CPU inference runtime. Run this 3-step test on your own machine.

Step 01 · Zero Dependencies

Install the single binary

Download the portable NC binary from nc.devheallabs.in. Record the installed binary digest and OS platform before testing.

Step 02 · Compile & Execute

Run an NC workflow

Save show "Hello from NC!" as app.nc and execute nc app.nc, or inspect complete service examples in github.com/devheallabs-ai.

Step 03 · Air-Gap Proof

Disconnect the network

Configure local CPU model files with NC AI, disable your network interface, and repeat the inference request. Verify zero external packet egress, latency, and deterministic output.
