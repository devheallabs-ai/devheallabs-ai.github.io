The Shift

AI Systems Are Becoming Infrastructure

Software used to be simple to reason about: code, test, deploy, monitor. Modern AI systems are not one artifact — they are a composition of a model, an agent, tools, memory, data, policies, infrastructure and business workflow, wired together and run continuously. That composition produces emergent behavior, and emergent behavior produces new classes of failure that traditional software engineering was never built to catch.

Traditional software engineering practices — unit tests, staging environments, uptime monitors — are necessary but not sufficient to fully test, validate and operate systems where behavior emerges from the interaction of a model, an agent, and the tools it calls. That gap is the reason DevHeal exists.

The Category

Introducing AI Systems Engineering

AI Systems Engineering is the discipline of engineering autonomous AI systems with the same rigor traditional infrastructure demands — not just prompting a model, and not just wrapping an API. It combines:

AI Systems Engineering

In practice this means: compiling and executing AI-native programs (not just calling an API), giving agents typed tools and bounded memory instead of ad-hoc scripts, testing a system's behavior against realistic scenarios before it touches production, evaluating it on task success and policy compliance rather than model accuracy alone, and giving it a way to recover state when a step in the middle of a workflow fails. DevHeal is building the platform for each of those layers — some of it shipping today, most of it still being built in the open.

Flagship
Experimental AGP — Agent Governance Protocol
v0.3.2

The industry secured who an AI agent is. Nobody secured what moved its hand.

AGP governs how much each input may influence each output, and refuses a privileged action before it commits. Signed authorization capsules, signed compute edges, per-input caps, aggregate influence budgets, and causal receipts committed to a hash-chained ledger an auditor can verify offline.

75% → 0% attack success on an adversarial influence-spreading benchmark, with zero benign requests blocked

A C core plus a hardened HTTP gateway, 86 tests passing (core authorization logic verified under AddressSanitizer and UndefinedBehaviorSanitizer). MCP middleware gates tools/call in front of an existing server, so no agent needs rewriting. Working prototype, internally benchmarked — not yet a deployed product; see the full write-up.
