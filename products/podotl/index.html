Model architecture

A recurrent model for operational signals.

Podotl uses a gated linear state-space model (GL-SSM). A compact recurrent state carries context forward while input-dependent gates control what is retained and updated.

Fused signals

Project numerical telemetry into model representations alongside log and support-ticket tokens.

Diagnostic and planning heads

Generate diagnostic outputs and remediation proposals from the shared operational representation.

Neuro-symbolic checks

Use Z3/Presburger verification to check encoded preconditions and postconditions for supported action contracts.

State update and verification boundary

h_t = alpha_t ⊙ h_(t−1) + beta_t ⊙ (W_in x_t)

Input-dependent decay and selectivity update a fixed-size recurrent state. This avoids a growing attention KV cache for the recurrent model state.

Formal checks apply to the encoded contract and its assumptions. Operational permissions, action adapters, and post-action health verification remain part of the surrounding system.
