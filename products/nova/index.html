Infrastructure intelligence model

Nova
Operational intelligence.
Inside your environment.

Turn infrastructure logs and alerts into focused triage, agent routing, and relevant runbook recommendations. Nova brings specialised model intelligence to private infrastructure workflows.

Request a free pilot →Explore the engineering
Purpose-built intelligence

Help your team find the next useful step.

Triage infrastructure signals

Interpret technical logs and alerts with a tokenizer designed around operational terms and telemetry.

Route work to specialists

Select a relevant agent domain or escalate when the available evidence does not support a confident route.

Retrieve relevant runbooks

Match incidents and proposed actions through semantic representations, then apply action checks.

Model architecture

One backbone. Five specialised heads.

A transformer backbone with contract-lattice working states connects language diagnostics, agent routing, execution gating, confidence scoring, and contrastive retrieval.

Private deployment

Run locally on CPU or GPU, with PyTorch, SafeTensors, LibTorch, and ONNX deployment formats.

Operational interfaces

Use the triage and action-judge interfaces to connect Nova with your own tools and approval workflows.

Action review

Combine destructive-pattern checks, incident/action relevance, and model gate scores to approve, request peer review, reject, or abstain.

Technical specification
Backbone
12 transformer layers; hidden width 576
Working states
12 contract-lattice slots; 3 routing steps
Tokenizer
32,881 BPE vocabulary; 20 telemetry token classes
Input window
160 tokens for focused log and alert inputs
Service interfaces
POST /v1/triage and POST /v1/judge
